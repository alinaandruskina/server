## Приемочное (функциональное) тестирование

### Тест А1. Проверка полного цикла взаимодействия (Happy Path)

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Успешная аутентификация и бинарный обмен данными |
| **Тип теста** | Позитивный |
| **Краткое описание** | Проверка прохождения всех 11 шагов протокола TCP с использованием эталонного клиента |
| **Предусловия** | Сервер запущен: `./vcalc_server --run -p 33333 -d clients.conf`. База содержит `user:P@ssW0rd`. Доступен `client_double`. |
| **Входные данные** | `./client_double -H SHA1 -S server` |
| **Ожидаемый результат** | 1. Клиент получает SALT (16 hex-символов). <br> 2. Получает ответ "OK". <br> 3. Передает 4 вектора в бинарном формате. <br> 4. Получает 4 результата типа double. <br> 5. Соединение закрыто корректно. |
| **Фактический результат** | SALT: `04D84F256DA5852C` (16 симв.). Auth: OK. Результаты: 10, 420000, 430000, -24.2. |
| **Итог** |  Пройден |

### Тест А2. Проверка обработки ошибки идентификации

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Отказ в выдаче SALT для неизвестного пользователя |
| **Тип теста** | Негативный |
| **Краткое описание** | Проверка реакции сервера на несуществующий LOGIN до этапа хеширования |
| **Предусловия** | Сервер запущен. В базе нет пользователя `ghost`. |
| **Входные данные** | Подключение через telnet/nc: `echo -n "ghost" \| nc 127.0.0.1 33333` |
| **Ожидаемый результат** | Сервер немедленно возвращает строку "ERR" и разрывает соединение. SALT не генерируется. |
| **Итог** |  Пройден |

### Тест А3. Проверка обработки ошибки аутентификации

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Отказ после проверки неверного HASH |
| **Тип теста** | Негативный |
| **Краткое описание** | Пользователь существует, но пароль неверный. Сервер должен принять LOGIN и SALT, но отказать после HASH. |
| **Предусловия** | Сервер запущен. Пользователь `user` есть, но его пароль в базе изменен на `wrong`. |
| **Входные данные** | `./client_double -H SHA1 -S server` (клиент шлет хеш от `P@ssW0rd`) |
| **Ожидаемый результат** | Сервер возвращает "ERR" после получения хеша. Соединение разрывается. Данные векторов не запрашиваются. |
| **Итог** |  Пройден |

### Тест А4. Проверка формата SALT и хеша

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Корректность генерации SALT16 |
| **Тип теста** | Позитивный |
| **Краткое описание** | Анализ вывода клиента/лога на соответствие требованиям к разрядности и формату |
| **Предусловия** | Сервер запущен. Запущен `client_double`. |
| **Входные данные** | Анализ вывода клиента при успешной аутентификации |
| **Ожидаемый результат** | Длина SALT = 16 символов. Все символы ∈ [0-9, A-F]. Регистр букв верхний. Digest size SHA-1 = 20 байт (40 hex-символов). |
| **Итог** |  Пройден |

### Тест А5. Проверка обработки переполнения

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Возврат +/- бесконечности при переполнении double |
| **Тип теста** | Позитивный / Граничный |
| **Краткое описание** | Передача вектора с значениями, сумма которых превышает DBL_MAX |
| **Предусловия** | Сервер запущен. Есть модифицированный клиент или возможность отправить спец. вектор. |
| **Входные данные** | Вектор: `[1.7e308, 1.7e308]` |
| **Ожидаемый результат** | Сервер возвращает `+inf` (или `-inf` для отрицательных). Программа не падает. |
| **Итог** |  Пройден |
