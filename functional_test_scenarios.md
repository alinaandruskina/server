## Введение
Функциональное тестирование проводилось для проверки соответствия программы требованиям Технического задания (ТЗ) и методических указаний. Тестирование включало проверку пользовательского интерфейса (п. 4.2.6 ТЗ), протокола взаимодействия (п. 4.2.3 ТЗ) и устойчивости работы сервера.



## Тестовые сценарии для программы-сервера

### Тест 1. Проверка текстового сообщения справки программы

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Вывод справки при запуске без параметров |
| **Тип теста** | Позитивный |
| **Краткое описание** | Проверка вывода текста справки при старте сервера без аргументов командной строки |
| **Предусловия** | Программа `vcalc_server` скомпилирована и находится в текущей директории |
| **Входные данные** | Команда: `./vcalc_server` |
| **Ожидаемый результат** | В консоль выводится текст справки с описанием ключей `-h`, `-p`, `-d`, `-l`, `--run`. Программа завершает работу с кодом 0. |
| **Постусловие** | Сервер не запущен. Готовность к следующему тесту обеспечена. |
| **Итог** |  Пройден |

### Тест 2. Проверка текстовых сообщений при передаче неверных параметров

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Обработка неизвестного параметра |
| **Тип теста** | Негативный |
| **Краткое описание** | Проверка реакции сервера на несуществующий ключ командной строки |
| **Предусловия** | Программа скомпилирована. Порт 33333 свободен. |
| **Входные данные** | Команда: `./vcalc_server --unknown_param` |
| **Ожидаемый результат** | Вывод сообщения об ошибке "Неизвестный параметр" и текста справки. Сервер не запускается. |
| **Постусловие** | Программа завершена. Порт свободен. |
| **Итог** |  Пройден |

### Тест 3. Проверка запуска с параметрами по умолчанию

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Запуск сервера с дефолтными настройками |
| **Тип теста** | Позитивный |
| **Краткое описание** | Проверка корректного старта сервера без явного указания порта, базы и лога |
| **Предусловия** | Файл `clients.conf` создан с содержимым `user:P@ssW0rd`. Порт 33333 свободен. |
| **Входные данные** | Команда: `./vcalc_server --run &` |
| **Ожидаемый результат** | Сервер запущен (PID активен). Слушается порт 33333. Создан/обновлен файл `server.log`. В логе запись: "Select variant double:SHA1:server". |
| **Постусловие** | Сервер работает в фоне. Для следующих тестов используется этот экземпляр. |
| **Итог** |  Пройден |

### Тест 4. Проверка текстовых сообщений при ошибках чтения данных

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Отсутствие файла базы клиентов |
| **Тип теста** | Негативный |
| **Краткое описание** | Проверка поведения сервера при отсутствии файла `clients.conf` |
| **Предусловия** | Файл `clients.conf` удален. Порт 33333 свободен. |
| **Входные данные** | Команда: `./vcalc_server --run -d missing.conf` |
| **Ожидаемый результат** | В лог или консоль выводится сообщение об ошибке открытия файла. Сервер либо создает файл по умолчанию, либо корректно завершает работу (не крашится). |
| **Постусловие** | Файл `clients.conf` восстановлен для дальнейших тестов. |
| **Итог** |  Пройден |

### Тест 5. Проверка работы при всех корректных входных значениях (Happy Path)

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Успешная аутентификация и передача векторов |
| **Тип теста** | Позитивный |
| **Краткое описание** | Проверка полного цикла взаимодействия с использованием эталонного клиента |
| **Предусловия** | Сервер запущен (из Теста 3). База содержит `user:P@ssW0rd`. Доступен `client_double`. |
| **Входные данные** | Команда: `./client_double -H SHA1 -S server` |
| **Ожидаемый результат** | Клиент получает SALT (16 hex-цифр). Аутентификация проходит успешно (ответ "OK"). Передаются 4 вектора. Получаются 4 суммы (10, 420000, 430000, -24.2). Соединение закрыто. |
| **Постусловие** | Данные обработаны верно. Сервер продолжает работу. |
| **Итог** |  Пройден |

### Тест 6. Проверка устойчивости (Некритические ошибки)

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Множественные подключения и разрывы соединений |
| **Тип теста** | Позитивный / Стресс-тест |
| **Краткое описание** | Проверка работы сервера после серии подключений с некорректными данными |
| **Предусловия** | Сервер запущен на порту 33333. |
| **Входные данные** | Цикл из 10 подключений через `client_double` с прерыванием или некорректными данными. |
| **Ожидаемый результат** | Сервер логирует ошибки подключений, но процесс `vcalc_server` остается активным (PID не меняется). Порт 33333 доступен для новых соединений. |
| **Постусловие** | Сервер остановлен командой `kill %1`. |
| **Итог** |  Пройден |

## Заключение
В ходе функционального тестирования были проверены все ключевые требования ТЗ:
1.  Корректная работа интерфейса командной строки (справка, параметры).
2.  Соответствие протокола аутентификации (SHA-1, SALT16) и обмена данными (бинарный формат double).
3.  Устойчивость сервера к ошибкам ввода и множественным подключениям.
