## Тестовые сценарии взаимодействия с Клиентом (Протокол)

### Тест 7. Успешная аутентификация и передача данных

| Поле | Значение |
| :--- | :--- |
| **Название теста** | Полный цикл работы (Happy Path) |
| **Тип теста** | Позитивный |

| **Предусловия** | Сервер запущен. База содержит `user:P@ssW0rd`. Клиент `client_float` доступен. |
| **Входные данные** | `./client_float -H SHA1 -S s` (подключается к 127.0.0.1:33333) |
| **Ожидаемый результат** | Клиент выводит "OK", передает 4 вектора, получает 4 суммы. Соединение закрыто корректно. |
| **Постусловие** | Данные обработаны верно |
| **Итог** |  Пройден |
