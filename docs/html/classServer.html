Detailed Description

Основной класс TCP-сервера.

Реализует логику приема соединений, аутентификации клиентов и обработки запросов на вычисление суммы векторов. Сервер работает в цикле, принимая подключения и обрабатывая их последовательно.

Протокол работы:

  1. Клиент отправляет логин
  2. Сервер генерирует соль и отправляет клиенту
  3. Клиент вычисляет хеш от соли и пароля, отправляет серверу
  4. Сервер проверяет хеш и отправляет OK или ERR
  5. При успехе клиент отправляет векторы, сервер возвращает суммы
