Detailed Description

Класс для реализации криптографической аутентификации.

Использует библиотеку Crypto++ для генерации случайной соли и вычисления хеш-функции SHA-1 от конкатенации (соль + пароль). Схема аутентификации: сервер генерирует соль, клиент вычисляет хеш от соли и пароля, сервер проверяет хеш.

Вычисляет хеш SHA-1 от соединения соли и пароля.

Формула: HASH = SHA1(salt + password). Результат преобразуется в 40-символьную HEX-строку.

Parameters

Генерирует случайную соль заданной длины.

Использует криптографически стойкий генератор псевдослучайных чисел (AutoSeededRandomPool из Crypto++). Соль генерируется как 8 случайных байт и преобразуется в 16-символьную HEX-строку.

Returns
std::string Строка соли в HEX-формате (16 символов, 0-9, A-F).
