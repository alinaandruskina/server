\doxysubsection{Detailed Description}
Основной класс TCP-\/сервера. 

Реализует логику приема соединений, аутентификации клиентов и обработки запросов на вычисление суммы векторов. Сервер работает в цикле, принимая подключения и обрабатывая их последовательно.

Протокол работы\+:
\begin{DoxyEnumerate}
\item Клиент отправляет логин
\item Сервер генерирует соль и отправляет клиенту
\item Клиент вычисляет хеш от соли и пароля, отправляет серверу
\item Сервер проверяет хеш и отправляет OK или ERR
\item При успехе клиент отправляет векторы, сервер возвращает суммы 
\end{DoxyEnumerate}
