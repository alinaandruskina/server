\doxysubsection{Detailed Description}
Класс для реализации криптографической аутентификации. 

Использует библиотеку Crypto++ для генерации случайной соли и вычисления хеш-\/функции SHA-\/1 от конкатенации (соль + пароль). Схема аутентификации\+: сервер генерирует соль, клиент вычисляет хеш от соли и пароля, сервер проверяет хеш.
